# AI Researcher

An AI-powered research assistant built using LangChain.

## Features

- Search research papers from arXiv
- Parse arXiv XML responses
- Download and extract text from research PDFs
- Generate professional PDF reports using LaTeX
- Cross-platform LaTeX compiler detection (Tectonic / MiKTeX)

## Tech Stack

- Python
- LangChain
- Requests
- PyPDF2
- LaTeX
- MiKTeX / Tectonic
